# 📌 РАЗДЕЛ 2. Домашнее задание #2: «Двухуровневая рекомендательная система»
**Файл решения:** [`HW2 (1).ipynb`](file:///c:/Users/fburl/Desktop/Prog/ML/HW2%20(1).ipynb) (также скопирован в [`ДЗ2 .ipynb`](file:///c:/Users/fburl/Desktop/Prog/ML/ДЗ2%20.ipynb))

### 📋 Выполнение требований ТЗ (ДЗ #2):

- [x] **Пункт 1: Инкапсуляция пайплайна в функцию `solution`**
  - **Требование ТЗ:** Все этапы (предобработка, генерация кандидатов, фичи, обучение реранкера, выдача рекомендаций) должны быть упакованы внутри функции `solution(train, users, items)`.
  - **Реализация:** Функция полностью автономна, принимает на вход тренировочные датафреймы и возвращает итоговый датафрейм рекомендаций формата `[user_id, item_id, rank]`.

---

- [x] **Пункт 2: Построение первого уровня (Генераторы кандидатов)**
  - **Требование ТЗ:** Использовать эффективный отбор релевантных кандидатов для ускорения и повышения полноты рекомендаций.
  - **Реализация:** Построен ансамбль из 3 независимых генераторов:
    1. `PopularModel` (скользящее окно 60 дней) — извлечение актуальных трендов.
    2. `ImplicitALSWrapperModel` (`factors=8`, `alpha=15.0`) — учёт скрытых вкусов пользователей.
    3. `EASEModel` (`regularization=500.0`) — автоэнкодер на основе паттернов совместных просмотров.
  - **Статус:** Формируется сбалансированный пул из 40–80 кандидатов на пользователя.

---

- [x] **Пункт 3: Построение второго уровня (Feature Engineering + CatBoost Reranker)**
  - **Требование ТЗ:** Добавить фичи пользователей, контента и взаимодействия для точного ранжирования кандидатов.
  - **Реализация:** Сгенерировано 24 признака:
    * *Пользовательские:* активность (`u_n_watches`), среднее время (`u_mean_dur`), средний процент досмотра (`u_mean_watched_pct`), соцдем.
    * *Контентные:* популярность за 14/30/60 дней, тип контента, возрастной рейтинг, год релиза, детский флаг.
    * *Признаки моделей 1-го уровня:* скоры и ранги (`rank_pop`, `rank_als`, `rank_ease`), а также Reciprocal Rank Fusion скор:
      $$\text{RRF\_Score} = \frac{1}{30 + \text{rank}_{\text{pop}}} + \frac{1}{30 + \text{rank}_{\text{als}}} + \frac{1}{30 + \text{rank}_{\text{ease}}}$$
    * *Обучение:* `CatBoostClassifier` с валидацией по историческому окну.

---

- [x] **Пункт 4: Достижение целевой метрики качества**
  - **Требование ТЗ:** Превысить порог $\text{MAP@10} \ge 0.0950$ на отложенной тестовой неделе.
  - **Результат:** Получено значение **$\mathbf{MAP@10 = 0.09858}$** (уверенно превосходит целевой порог $0.0950$).
